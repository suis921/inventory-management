# 学生団体在庫管理アプリ

Python / Tkinterで開発した、学生団体向けの在庫管理アプリです。

## 概要

科学工作イベントで使用する材料・備品の在庫を管理するために開発しました。
実際の団体活動で使用しており、メンバーからのフィードバックをもとに機能改善を行っています。

## 主な機能

- 在庫情報の一覧表示
- 在庫数量の編集
- 物品情報の編集
- CSVファイルによるデータ管理

## 使用技術

- Python
- Tkinter
- CSV

## 開発背景

団体活動における在庫管理の効率化を目的として開発しました。
メンバーの意見を取り入れ、在庫数量を直接編集できるようにするなど、実用性を重視した改善を行っています。

## 実行方法

### 動作環境

### Pythonから実行

必要なライブラリをインストールします。

```bash
pip install -r requirements.txt
```

アプリケーションを実行します。

```bash
python inventory-management.py
```

### exeファイルのビルド

PyInstallerを使用してexeファイルを生成できます。

```bash
pyinstaller inventory-management.spec
```

生成されたexeファイルは `dist` ディレクトリ内に配置されます。

## 注意事項

- CSVファイルを使用して在庫情報を管理します。
- 動作確認用のサンプルデータを同梱しています。
